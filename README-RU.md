# SPM Studio — полный проект

Версия сайта: 6. Исходный коммит: 33f7fb5c754d3fb0797414f2fafcf1b2451ca0e3.
Онлайн-сайт: https://spm-studio-olia.lilacghost2.chatgpt.site

## Что включено
- Полные HTML, CSS и JavaScript, дизайн, английский и китайский интерфейс.
- Курсы, учебные материалы, редактор уроков, тесты и остальные разделы сайта.
- 12 исходных пользователей: 1 администратор, 1 преподаватель, 10 студентов.
- Сервер входа, серверная проверка роли, добавление/изменение/удаление пользователей.
- SQL-схема, начальные данные, миграции, сборка Worker и конфигурация Sites.
- Автоматические проверки и отдельный тестовый сервер.
- Дополнительный локальный сервер с постоянной SQLite-базой и запуск для Windows/macOS/Linux.

## Быстрый запуск на Windows
1. Установи Node.js версии 24 или новее (он включает npm).
2. Распакуй ВСЮ папку SPM-Studio из ZIP. Не запускай файлы внутри ZIP.
3. Запусти START-WINDOWS.bat.
4. Открой http://localhost:3000 в браузере. Окно сервера должно оставаться открытым.
5. Остановка: Ctrl+C. Повторный запуск не удаляет аккаунты.

Альтернатива из терминала IntelliJ IDEA или обычного терминала в папке проекта:

    node scripts/build-worker.mjs
    npm start

Сторонние npm-пакеты не нужны. Tomcat для этого проекта не используется.
Не открывай dist/index.html двойным щелчком: вход требует работающего сервера.

## macOS / Linux
В терминале из папки проекта:

    sh START-MAC-LINUX.sh

Затем открой http://localhost:3000.

## Вход и пользователи
Используй прежние имя и ID. Данные хранятся как хеши: полные ID администратора,
преподавателя и трёх демонстрационных студентов из них восстановить нельзя.
Если ID Olia неизвестен, для ЛОКАЛЬНОЙ копии выполни:

    npm run setup-admin

Выбери новый ID, затем войди под именем Olia. Эта команда не меняет онлайн-сайт.
Введённый ID виден в терминале. У администратора: User management → Add user / Edit / Delete.
При переименовании пользователя повторно введи его ID; при остальных изменениях
можно оставить ID пустым, чтобы сохранить прежний. Удаление требует подтверждения.
Своя учётная запись защищена от удаления и снятия роли администратора.

## Где сохраняются данные
- Локальные пользователи и сессии: data/spm.sqlite. Папка создаётся при запуске.
- Для резервного копирования останови сервер и скопируй всю папку data.
- Учебные заметки, изменения уроков, предпочтения и прочая демонстрационная активность
  используют localStorage конкретного браузера. Они не синхронизируются между устройствами.
- Онлайн-сайт использует свою D1-базу. Локальная база полностью отдельная.
- В ZIP включены исходные 12 аккаунтов, а НЕ выгрузка текущей онлайн-базы и НЕ данные
  из браузера пользователя. Поздние изменения онлайн-пользователей в ZIP не включены.
- Открытие localhost создаёт новое браузерное рабочее пространство; настройки с
  домена chatgpt.site не переносятся автоматически.

## Проверки

    npm test

Проверяются сессии без cookie, права ролей, CRUD, вход по новым данным,
отзыв старых сессий, редактирование администратора и выход.

npm run dev предназначен ТОЛЬКО для разработчика: тестовая база находится в памяти,
содержит дополнительного QA-пользователя и исчезает при остановке. Для использования
проекта всегда выбирай npm start / START-WINDOWS.bat.

## Публикация
Исходная .openai/hosting.json содержит идентификатор существующего сайта и привязку DB.
Это не пароль. Архив не содержит прав доступа к Sites или ключей публикации.
Для повторного размещения в Sites нужна авторизация владельца. Для другого сайта
нужно заменить project_id на выданный ему идентификатор. Серверная сборка:

    npm run build

Результат: dist/server/index.js. D1-миграции находятся в drizzle/.
Обычный статический хостинг без сервера не поддерживает вход и управление пользователями.
Локальный сервер слушает только 127.0.0.1 и предназначен для демонстрации на компьютере.
Для публичного использования нужна отдельная конфигурация размещения и HTTPS.

## Состав папок
- dist/: интерфейс и готовая серверная сборка.
- worker/: серверный исходный код и начальный список аккаунтов.
- drizzle/: SQL-схема и журнал миграций.
- scripts/: сборка.
- local/: локальная постоянная база, сервер и настройка администратора.
- tests/: проверки и изолированный тестовый сервер.
- USERS.csv: список исходных пользователей (ID отображаются с маской).
- SHA256SUMS.txt: контрольные суммы файлов.

Учебная авторизация использует имя + ID, как было запрошено. Это не полноценная
университетская система с паролями, восстановлением доступа и подтверждением личности.
